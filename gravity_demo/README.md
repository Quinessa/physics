# Gravity Demo

This is an interactive 3‑D gravity simulation showcasing Newtonian and Screened-Poisson force laws.

## Installation

Ensure Python 3.8+ with the following packages:

```
pip install numpy pygame moderngl pyrr imgui-bundle
```

## Running

```
python -m gravity_demo.main
```

Press `TAB` to toggle force laws, `R` to reset the scene, `Space` to pause, and use the mouse wheel to zoom.
